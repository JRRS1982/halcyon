# Stakeholder Mapping

This document helps identify and manage all parties with an interest in the project's success. It is a living document that should be updated as the project progresses and hopefully enables better communication and collaboration.

## How to Use This Template

1. List / update all potential stakeholders
2. Categorize the role and influence of each stakeholder
3. Define engagement strategy
4. Track communication and updates
