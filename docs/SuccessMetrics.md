# Success Metrics

## Business/User Value Metrics (The "Why")

1. What problem does your app solve?
2. What user outcomes indicate success?
3. Example metrics: user retention, task completion rate, user satisfaction score

## Technical Performance Metrics (The "How Well")

1. How fast and reliable is your app?
2. Example metrics: page load time (<3s), API response time (<500ms), uptime (99.9%)

## Engagement Metrics (The "How Much")

1. How are users interacting with your app?
2. Example metrics: daily/monthly active users, session duration, feature adoption rate

## Quality Metrics (The "How Good")

1. How stable and maintainable is your codebase?
2. Example metrics: error rate (<1%), test coverage (>80%), build success rate

## Growth Metrics (Optional, The "How Many")

1. How is your user base growing?
2. Example metrics: user acquisition rate, conversion rate, viral coefficient
