# Spike [IssueId] : [Title]

A spike is carried out when there is uncertainty about how to solve a problem or when there is a need to understand a problem better. It is a way to explore a problem and come up with a solution which can then be used to inform the development of the product.

## Summary

Insert a summary of the findings from the spike in one or two sentences. It should let the reader know if the spike was successful or not, i.e. do we have a solution to the problem or not, and if there are risks that the proposed solution will not be successful. It should briefly mention and size/scale those risks.
